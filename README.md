# TodoApp

A simple and modern Todo List application built with React Native and Expo.

## Features

- Add new tasks
- Mark tasks as completed
- Mark completed tasks as incomplete
- Delete tasks
- View remaining tasks
- Clean and modern dark user interface
- React Native useState Hook
- FlatList for displaying tasks

## Technologies Used

- React Native
- Expo
- JavaScript
- React Hooks

## Installation

1. Clone this repository.
2. Install dependencies:

   npm install

3. Start the application:

   npx expo start
