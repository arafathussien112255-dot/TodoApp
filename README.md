# Todo List App (React Native + Expo)

A modern task list app built for Lab Task 1.

## Features
- Add tasks dynamically
- Display tasks with `FlatList`
- Mark tasks complete/incomplete
- Delete tasks
- Remaining task counter
- Modern dark UI

## Run
1. Install Node.js (LTS) and Expo prerequisites.
2. Open a terminal in this project folder.
3. Run:
   ```bash
   npm install
   npx expo start
   ```
4. Scan the QR code with Expo Go, or press `a` to open Android emulator.
